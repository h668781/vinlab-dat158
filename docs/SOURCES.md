6. [Google Production ML systems](https://developers.google.com/machine-learning/crash-course/production-ml-systems). Skiljet mellom trening, inferens, datakontroll og vedlikehald.
8. [GitHub Pages custom workflows](https://docs.github.com/en/pages/getting-started-with-github-pages/using-custom-workflows-with-github-pages). Dokumentasjon av den statiske publiseringsflyten.
